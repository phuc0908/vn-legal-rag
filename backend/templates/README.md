# Thư mục file mẫu (templates)

Đặt các file mẫu để người dùng tải về tại đây.

## Lộ trình ly hôn
- Đặt file mẫu đơn ly hôn với tên chính xác: **`mau-don-ly-hon.docx`**
- Endpoint phục vụ: `GET /api/roadmap/divorce/template` (chỉ gói Pro mới tải được).
- Nếu chưa có file, endpoint trả 404 và nút tải trên giao diện sẽ báo lỗi.
